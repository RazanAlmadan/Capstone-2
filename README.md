## 📌 About

**Tasmeem Hub** is a web-based design marketplace developed as my **second capstone project** during the **Tuwaiq Academy Web Development using Java Bootcamp**.

The platform brings clients and designers together in one place, making it easier to discover designers, communicate, manage proposals, track projects, and complete design work.

---

## 🎯 Project Goal

Tasmeem Hub aims to make working with designers more organized by providing:

- 👤 Designer discovery
- 💬 Client–designer communication
- 📩 Project requests
- 📄 Project proposals
- 🤖 AI-powered features
- 📦 Order and project tracking
- 🖼️ Project draft review
- 💳 Structured payments
- 📧 Email notifications and reminders

---

## 👥 User Roles

### 👤 Client

Clients can:

- Browse designer profiles and work.
- Find designers using AI-powered image style search.
- Send project requests.
- Communicate with designers through chat.
- Review and accept or reject proposals.
- Track their orders.
- Review submitted project drafts.
- Accept drafts or request revisions.
- Complete project payments.

### 🎨 Designer

Designers can:

- Manage their profile and showcase their work.
- Receive and respond to project requests.
- Communicate with clients through chat.
- Create proposals manually.
- Generate proposal drafts using AI.
- Manage accepted orders.
- Submit project drafts for client review.
- Revise rejected drafts.
- Receive deadline reminders.


---

## 🤖 AI Features

### 🔍 Find Designers by Image Style

Clients can upload a reference image and use AI to find designers whose work matches the visual style of the image.

### ✨ AI-Assisted Proposal Generation

Designers can use their conversation with the client to generate a proposal draft. The designer can review and edit the proposal before sending it.

## 🔄 How Tasmeem Hub Works

The platform follows a simple project workflow:

```text
Find Designer
      ↓
Send Project Request
      ↓
Designer Accepts
      ↓
Client ↔ Designer Chat
      ↓
Proposal
      ↓
Client Accepts
      ↓
Order + Bill
      ↓
20% Down Payment
      ↓
Work In Progress
      ↓
Draft Submitted
      ↓
Client Reviews
   ↙         ↘
Accept       Reject
  ↓             ↓
80% Payment   Revision
  ↓             ↓
Done       New Draft

```
---
## 🤖 AI Features

Tasmeem Hub includes two AI-powered features designed to make the design process easier:

- 🔍 **Find Designers by Image Style** — Clients can upload a reference image, and AI analyzes its visual style to help find designers with similar work.
- ✨ **AI-Assisted Proposal Generation** — Designers can use their client conversation to generate a proposal draft, then review and edit it before sending it.

These features use AI to **assist users while keeping the final decisions in their hands**.

---

## 📧 Email Notifications

Tasmeem Hub keeps users updated through automated email notifications for important project events:

- 📩 **New Project Request** — The designer is notified when a client sends a request.
- 🖼️ **Draft Submitted** — The client is notified when the designer submits a project draft.
- ⏰ **Deadline Reminder** — The designer receives a reminder when the deadline is reached and no draft has been submitted.
